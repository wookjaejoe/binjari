# 조사 4: 보이스앤톤 (한국어 중심 — 토스·배민 1차)

## 토스 — 공개된 원칙 전문

**보이스 vs 톤 정의 (원문)**
- "보이스는 목소리예요. … 목소리는 그 사람의 아이덴티티, 정체성에 가까워요. 반면 톤은 애티튜드, 태도에 가까워요."
- 가이드 5층: 코어밸류 → 프린시플 → 가이드라인 → 템플릿 → 시스템
- "'의미 없는 단어를 없애자'고 제시하는 게 프린시플이라면, '[혹시]는 의미 없는 단어다'라고 결정하는 게 가이드라인이죠."

**5 코어밸류**: Clear / Concise / Casual / Respect / Emotional
- Respect 원문: "당장 클릭하게 만들고, 전환시키고 싶은 마음에 코스트를 숨기거나 혜택을 더 크게 보이게 만들고 싶을 때가 있어요. 신뢰를 쌓는 것은 어렵지만 무너지는 것은 쉽죠."

**8 프린시플 (체크 질문)**
1. Predictable hint — 다음 화면을 예상할 수 있는 힌트가 있는가?
2. Weed cutting — 의미 없는 단어를 모두 제거했는가? ("넣든 빼든 의사 전달에 영향이 없는 단어를 잡초라고 불러요", "우리는 모바일 앱을 쓸 때 읽지 않아요. 스캔하죠.")
3. Remove empty sentences — 공간이 비어 보인다는 이유로 문구를 쓰지 않는다
4. Focus on key message — "때로는 정보를 생략해서 필요한 내용만 알려주는 것이 더 친절한 커뮤니케이션"
5. **Easy to speak** — "Easy to read가 아니라 speak", 소리 내어 읽어 어색하면(한자어·문어체·긴 호흡) 고친다
6. Suggest over force — "권유와 강요는 다릅니다", "불필요한 공포감을 조성해서 우리가 원하는 방향으로 유도하는 것도 피해야"
7. Universal words — 유행어·은어·밈 금지
8. Find hidden emotion

**존댓말**: "제품 안의 모든 문구는 '해요체'로 써요. **상황, 맥락을 불문하고**." 에러도 해요체.
- 채택 이유는 지표가 아니라 브랜딩. "지금 해요체가 토스의 톤을 구성하는 데에 가장 큰 역할"
- **캐주얼한 경어**: "'~시겠어요?', '시나요?', '~께' 같은 과도한 경어를 쓰지 않아요." 규칙: 동사에서 '~시' 빼기 / 계시다→있다 / 여쭈다→확인하다 / 께→에게 / 되어요→돼요
- 경어 예외 3종: 사용자 맥락을 활용한 질문 / 상황 추정 / 선의가 필요할 때(설문)

**능동·긍정**
- "수동형 문장은 특정 상황에서만" — 됐어요→했어요, '~었' 빼기
- "부정적 커뮤니케이션을 최대한 줄이고 긍정형 문장을" — 안 돼요/없어요 (X) → ~하면 할 수 있어요 (O)
- 부정형 허용 예외: 정책상 못 쓸 때(이유 병기), 일부 기능만 못 쓸 때, 민감한 안내
- 수동형 허용 예외: 종료·만료(주어 강조), 사용자에게 미치는 영향(연체·해지·적용)
- "'{명사}+{명사}' 쓰지 않기" — 한자어를 동사로 풀어쓴다

**버튼**: 액션 요청은 '~하기' / 화면 전환은 '확인'·'다음' / 왼쪽 버튼은 **'닫기'**("취소는 사용자가 하고 있는 작업이 취소된다고 오해할 수 있어 쓰지 않아요")

**마침표**: 제목 X, 본문 O (푸시 규칙)

**에러 6원칙**: 최상위 가치는 Navigating("사용자가 다음 단계로 무엇을 해야 할지"). 포함 요소 = 상황 설명 + 이유 + 해결책.
- "비밀번호를 틀렸어요 (X) / 김토스님의 정보가 아니에요 (O)"
- "별로 위급한 상황이 아닌데 빨간색을 써서 실제보다 더 심각한 상황처럼 전달"하지 않기
- "~해야 해요라고 강요하는 듯한 말투보다, ~할 수 있어요라고 권유하는 말투"

**금지어 목록(푸시)**: 지금 바로! / 초특가! / 역대급 / 긴급! / 대박 / 놓치면 후회해요 / 지금 안 하면 못 해요 / 느낌표 / 이모지
- "불안감을 조성하지 않아요. … 상황만 차분히 전달해 주세요."

**다크패턴 출시 불가 5조**: 진입 즉시 광고 시트 / 뒤로가기 시 알림 동의 시트 / 나갈 선택지 없음 / 예상 못한 전면 광고 / **CTA만 보고 다음 행동 예측 불가**

## 배민
- 원칙 목록 비공개. 구조만: "문장부호부터 날짜와 시간, 금액 표기까지" 시트로 관리, **컴포넌트 위치별 가이드**(토스트/버튼/타이틀/디스크립션).
- 공개된 유일한 표기 규칙: 기본은 '1만원', 마케팅에서만 '만원' 허용.
- 빈 화면 철학: "앱 사용자가 이용 중 원치 않는 상황에 직면했을 때 드는 불편한 감정을 최소화하고, '풋' 하거나 '아~'하는 감정을"
  - 기존 "포인트 상세내역이 없습니다."(합니다체) → "포인트 상자가 비어있어요"
  - 결정 기준: "행동 유도까지 하는 것보다 좀 더 포괄적인 의미"를 택함
  - CCO 피드백: "사용자들은 이 페이지를 액자로 보는 것이 아니라 흐름 속의 점으로 본다", "패러디는 지양하자"
- 버튼 사례: "2분 만에 끝내기" (동사형 + 실측 소요시간). "'2분'은 저와 동료들이 직접 순서를 따라가며 재본 건데요."

## 국내 여행·캠핑 앱 톤 (조사1에서)
- 캠핏 "금방 마감돼요!", "포기 금지" / 트리플 "골라줘요", "뚝딱" / 아고다 "놓치지 마세요!"
- 반면 글로벌 로컬라이즈(Google·Skyscanner·Hopper)는 합니다체 + 명사형 라벨 + 느낌표 0
- 공공 포털(국립공원·숲나들e)은 "~하시기 바랍니다" 격식체

## 추정치 고지 관행 (전 제품 공통)
- Skyscanner "달력에 표시된 가격은 참고용 가격입니다"
- Kayak "100% 정확할 수는 없습니다", "While not perfect"
- Google "updated approximately once every 24 hours"
